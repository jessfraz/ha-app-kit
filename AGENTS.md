# HA App Kit

Share contracts that already exist in the apps. Keep app data, routing,
authentication, provider permissions, and database schemas in their owners. Rust
consumers embed pinned assets; installed apps must not require a CDN, Node, or
another web server.

Use `nix develop` and the declared pnpm lockfile. Run `pnpm check`, Rust checks,
and native workflow validators for changes that affect them. Test the rendered
components, including mobile, dark mode, keyboard navigation, and dialogs.
Review baseline changes as images, not just passing snapshot updates.

Examples, tests, screenshots, and review prompts must use fictional data. Never
include household records, addresses, accounts, or credentials.
